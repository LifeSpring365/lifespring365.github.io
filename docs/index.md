## 欢迎来到 LifeSpring365

LifeSpring365 是一个持续成长的圣经学习与属灵资源网站。

这里保存逐章查经、每日灵修、神学思考、讲道与视频笔记、敬拜诗歌及学习资料。愿我们在神的话语中扎根，在基督里不断更新，并把所领受的真理分享给更多人。
