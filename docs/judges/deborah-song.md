# 底波拉之歌

**经文：士师记第5章**

## 一、这是一首得胜之后的敬拜诗

士师记第4章以叙事方式记录争战，第5章则以诗歌方式解释争战的属灵意义。底波拉与巴拉没有把荣耀归给军事策略，而是首先颂赞耶和华。

## 二、神使用甘心摆上的人

诗歌两次强调百姓“甘心牺牲自己”。神可以独自施行拯救，却乐意呼召祂的百姓参与祂的工作。

## 三、不同支派表现出不同回应

有些支派勇敢出战，有些支派犹豫观望。这提醒我们：面对神的呼召，人不能永远停留在分析、等待和旁观中。

## 四、底波拉“兴起作以色列的母”

这句话不是自我夸耀，而是对神所赐使命的承担。“母”的形象表达保护、引导、唤醒和属灵责任。底波拉的权柄不是来自自我抬高，而是来自神的呼召和她对百姓的服事。

## 五、雅亿的行动

雅亿以出人意料的方式终结西西拉的威胁，显明神常使用在人看来软弱、边缘或不可能的人完成祂的计划。

## 六、今日应用

- 得胜以后，要把荣耀归给神。
- 神寻找甘心回应的人，而不只是有能力的人。
- 不要让观望和拖延代替顺服。
- 属灵领袖的权柄应当表现为保护、唤醒与服事。
- 神能使用普通人完成不普通的使命。

## 讨论问题

1. 我目前在哪一件事上仍处于观望状态？
2. “甘心摆上”与冲动行事有什么区别？
3. 底波拉作为“以色列的母”，对今日属灵带领有什么提醒？
